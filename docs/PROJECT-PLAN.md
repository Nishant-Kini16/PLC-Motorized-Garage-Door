# Project Plan

## Project title

PLC-Based Motorized Garage Door Control System Using Limit Sensors and Motor Interlocking

## Domain

Industrial Automation

## Application area

Residential and industrial access automation

## Objectives

- Develop PLC ladder logic for opening and closing a motorized garage door.
- Use separate OPEN and CLOSE push buttons.
- Stop motion at the corresponding end positions using limit switches.
- Use holding logic where appropriate.
- Prevent simultaneous opening and closing commands through interlocking.
- Test and document the control system.

## Planned deliverables

- I/O address table
- Ladder diagram created in the PLC programming software
- Hardware wiring diagram
- List of components and specifications
- Test plan with actual results
- Final project report and photographs of the prototype
